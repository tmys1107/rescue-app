# sources/ 管理インデックス

ここは「アプリのデータ元となる素材」を保管する場所です。
Webアプリには読み込まれません（開発・運用用）。

---

## フォルダの役割

```
sources/
├── shared/              ← 複数資器材にまたがる素材
└── {ID}_{資器材名}/     ← 1つの資器材に固有の素材・統合メモ
```

---

## 素材を新たに追加するとき

- 1つの資器材に関する素材 → `sources/{ID}_{資器材名}/` フォルダに置く
- 複数資器材にまたがる素材（操法メモなど） → `sources/shared/` に置く

ファイル名は内容が分かるものにする（例：`チルホール_補足.md`、`現場で気づいたこと.md`）。
著者・出典を覚えていれば文書内に書く。覚えていなくても問題なし。

---

## 資器材データへの取り込み手順

1. 強化したい資器材の `sources/{ID}_{資器材名}/` を確認（なければ作る）
2. shared/ から該当資器材の情報を探す
3. 統合した情報を `入力.md` にまとめる
4. カブトに「これでお願い」と渡す → equipment.json に反映
